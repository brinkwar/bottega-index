# pipeline

Run the tests from this folder: `python3 test_score.py`.

`score.py` is BOTTEGA_SCORE_V40. `patches/` holds the guarded patches V35-V40 that
took the frozen V34 to V40, in order; each states what it changed and why, and
none changes the rendered prompt.

`discover.py` identifies the harvester to catalogue sites. The 2026 harvest
sent `https://artmorph.org/bottega-index/method`; the contact was then extended
to include hello@artmorph.org. It affects no result.
